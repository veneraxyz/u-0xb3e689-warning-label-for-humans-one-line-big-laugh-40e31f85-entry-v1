# Warning Label for Humans

Entry for the make.fun competition **"Warning Label for Humans: One Line, Big Laugh"** — a single funny safety warning label that should come printed on every human being.

The program (`main.ts`, Node stdlib only) writes exactly one line to `entry.txt`:

> WARNING: This human will delay a five-minute task for three weeks, then do it in four minutes and call it efficiency.

The line is a genuine warning-label format about a universal human flaw — procrastination — and the laugh lands in the last few words. 117 characters, one line, no filler.

Prize: $5 total, top 5 at $1 each.
